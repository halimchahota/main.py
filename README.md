# Institutional Adaptive Trading Bot 🤖📈

بوت تداول ذكي متقدم يستخدم الذكاء الاصطناعي والتحليل الفني المتطور مع Telegram.

## ✨ المميزات الرئيسية:

### 📊 التحليل الفني المتقدم:
- **RSI** - مؤشر القوة النسبية
- **MACD** - تقارب وتباعد المتوسطات المتحركة
- **Volume** - تحليل حجم التداول
- **Momentum** - تحليل الزخم
- **ATR** - متوسط النطاق الحقيقي
- **Fibonacci** - مستويات فيبوناتشي
- **Support/Resistance** - الدعم والمقاومة

### 🔥 المحركات المتقدمة:
- **Wyckoff** - تحليل مراحل ويكوف
- **Smart Money Concepts (SMC)** - مفاهيم المال الذكي
- **BOS/CHOCH** - كسر الهياكل والتغيير
- **Liquidity Sweep** - مسح السيولة
- **Displacement** - تحليل الإزاحة

### 🧠 التعلم الآلي:
- نظام تعديل الأوزان التلقائي
- التعلم من الصفقات الفائزة والخاسرة
- تحسين الأداء المستمر

### 📱 التكامل مع Telegram:
- إشارات فورية للصفقات
- تحليلات تفصيلية
- تقارير يومية
- إدارة الأوامر الفورية

## 🚀 التثبيت والإعداد:

### 1️⃣ استنساخ المستودع:
```bash
git clone https://github.com/halimchahota/main.py.git
cd main.py
```

### 2️⃣ تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 3️⃣ إعداد متغيرات البيئة:

**الطريقة الأولى: إنشاء ملف `.env`**
```bash
cp .env.example .env
```

ثم عدّل الملف بمعلوماتك:
```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN_HERE
CHAT_ID=YOUR_CHAT_ID_HERE
ACCOUNT_BALANCE=100
RISK_PCT=3
```

**الطريقة الثانية: متغيرات النظام**
```bash
export BOT_TOKEN="your_token_here"
export CHAT_ID="your_chat_id_here"
```

### 4️⃣ تشغيل البوت:
```bash
python main.py
```

## 🛠️ الإعدادات المهمة:

### إعدادات التداول:
```env
ACCOUNT_BALANCE=100          # رصيد الحساب بالدولار
RISK_PCT=3                   # النسبة المئوية للخطر
```

### إعدادات الفحص:
```env
CHECK_INTERVAL_SEC=45        # فترة الفحص بالثواني
COOLDOWN_MINUTES=25          # الوقت بين الإشارات
MIN_SCORE_TO_SIGNAL=7.8      # الحد الأدنى للإشارة
MIN_SCORE_GAP=1.8            # الفارق الأدنى بين BUY/SELL
```

### إعدادات الجلسة:
```env
USE_SESSION_FILTER=0         # تفعيل تصفية الجلسة
SESSION_START_UTC=7          # بداية جلسة التداول
SESSION_END_UTC=21           # نهاية جلسة التداول
```

### إعدادات المؤشرات:
```env
EMA_FAST=20                  # الحد الأسرع للمتوسط المتحرك
EMA_SLOW=50                  # الحد الأبطأ للمتوسط المتحرك
RSI_PERIOD=14                # فترة RSI
ATR_PERIOD=14                # فترة ATR
```

## 📈 كيفية عمل البوت:

### 1️⃣ جمع البيانات:
يحمل البوت البيانات من ثلاث أطر زمنية:
- **D1** (يومي) - للاتجاه العام
- **H4** (4 ساعات) - للتوجيه
- **M30** (30 دقيقة) - للإشارات الفورية

### 2️⃣ تحليل المؤشرات:
يحسب البوت أكثر من 13 مؤشر فني متقدم

### 3️⃣ حساب النقاط:
- يعطي كل مؤشر نقاط (من 0-10)
- يستخدم أوزان ديناميكية متعلمة
- يحسب الثقة النهائية

### 4️⃣ توليد الإشارة:
إذا تحقق شروط معينة:
- درجة التحديث ≥ 7.8
- الفارق بين BUY/SELL ≥ 1.8
- المؤشرات الإضافية موجودة

### 5️⃣ إرسال التنبيه:
- رسالة نصية مع التفاصيل
- صورة بياني الشارت
- تسجيل الصفقة في النظام
